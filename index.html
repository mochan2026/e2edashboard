Memeriksa koneksi Google Drive...
Agar berhasil dimuat: bagikan file sebagai "Anyone with the link" (atau, paling andal, gunakan File → Share → Publish to web → CSV untuk Google Sheets). Link Google Sheet otomatis diekspor sebagai CSV; link file Drive biasa (txt/csv) diambil langsung. Jika browser memblokir permintaan (CORS), gunakan opsi Publish to web.

Untuk ditanam di Google Sites / halaman lain: begitu link diisi dan berhasil dimuat sekali, browser akan mengingatnya dan otomatis menyambung lagi di kunjungan berikutnya — tidak perlu klik tombol lagi. Alternatif yang lebih pasti untuk embed: tambahkan link langsung di URL saat memasang iframe, contoh ...RBI_Dashboard.html?src_perhitungan=LINK1&src_finalscore=LINK2&src_snapshot=LINK3, dashboard akan langsung konek otomatis begitu dibuka.
